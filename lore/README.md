# Lore — como usar esta pasta

A lore de **The Third Light** ainda está **em aberto** por decisão do Rick. Este espaço organiza o que já
foi decidido, o que é apenas ideia e o que está proibido — para que ninguém "feche" a mitologia sem querer.

## Regras
1. **Nada aqui é definitivo** a menos que esteja marcado como `[DECIDIDO]`. O resto é `[IDEIA]`.
2. Lore entra no jogo **pelo ambiente** (objetos, marcas, ausências), nunca por textos explicativos. Sem documentos explicando entidades, sem símbolos religiosos, sem placas "sobrenaturais" — pelo menos até o Rick definir.
3. Referências religiosas/espirituais serão tratadas com muito cuidado e só com aprovação explícita.
4. As três entidades pertencem ao **mesmo universo físico**: T1 descobre a floresta, T2 entende a casa, T3 descobre o que há embaixo dela. Tecnicamente poderão ser Places diferentes da mesma experiência.
5. Nomes provisórios: Homem Lua, Homem Estrela, Homem Sol. "The Third Light / A Terceira Luz" = nome do jogo.
